### Como executar

- Precisa ter o gcc e o golang instalados na sua máquina;
- Se precisar instalar o golang: **[Instaland o golang](https://go.dev/doc/install)**


### Comandos para executar:
1. **Atualizando as branchs do repositório online:**

```bash
git fetch origin
```

2. **Confirmar se a branch foi baixada:**

```bash
git branch -a
```
3. **Mudando para a branch que deseja:**
```bash
git switch Gabriel
```
4. **Recompilar os programas:**
```bash
gcc questao01.c TAD-Vetorzao.c -o questao01.exe
```
```bash
gcc questao02.c TAD-Vetorzao.c -o questao02.exe
```
```bash
gcc questao03.c TAD-Vetorzao.c -o questao03.exe
```
```bash
go run visualizar_resultados.go
```
